ZeroTask Master Architecture Blueprint v2.0
1. The Unified Task Engine & Delegation Hierarchy
Entity Consolidation: The "Project" concept is eliminated. Everything is a Task. Tasks can have parent_task_id fields, allowing infinite nesting (e.g., A Department Head creates a massive Parent Task; a Manager breaks it down into Sub-tasks for Employees).

Role-Based Creation: Only Founders, Department Heads, and Managers can create tasks. The UI will strictly hide the creation buttons from Employees.

Delegation Flow: Managers can assign a portion of a task to themselves and distribute the remaining sub-tasks to multiple specific employees.

Priority Flags: Every task will include a visual priority badge: Low, Medium, High, or Urgent.

Smart Deadlines: Only Founders, Department Heads, and Managers can edit the deadline date. Employees are strictly restricted to updating the status and progress.

Progress Tracking: A 0-100% progress bar attached to every task, dynamically calculating the completion of its nested sub-tasks.

2. Departmental Silos & Advanced Filtering
Strict Isolation: Implementation of Supabase Row Level Security (RLS) policies based on a new department_id assigned to users. Operations cannot query, view, or search for Marketing tasks.

Advanced Filtering Engine: A robust UI panel allowing Department Heads and Managers to slice their massive workloads by: To-Do, In Progress, Done, Overdue, Delegated To, and Priority.

Employee Dynamic View: A simplified, distraction-free dashboard showing only their specific queue: Upcoming, To-Do, Done, and a clean empty state when all work is cleared.

3. Enterprise Security & Audit Logging
Immutable Audit Trail: An invisible backend table (audit_logs) that records every single state change. If an employee changes a task from "In Progress" to "Done", or if someone tampers with a progress bar, the system silently logs the user_id, task_id, previous_state, new_state, and timestamp.

Founder Oversight: A dedicated admin view for Founders to query these logs if an anomaly or dispute arises.

4. Communication & Collaboration Suite
Global Real-Time Chat (Slack Clone): A dedicated tab for company-wide and direct messaging using Supabase Realtime.

In-Task Activity Messaging: A localized comment thread securely attached to individual tasks for contextual discussions without cluttering the main chat.

Enterprise File Attachments: Integration with Supabase Storage allowing users to upload and preview PDFs, XLSX, PPTX, DOCX, and images directly inside tasks and chat threads.

Global Note-Taking: A private, markdown-supported scratchpad for every user to jot down daily notes, independent of specific tasks.

5. Gamification & External Integrations
Milestone Tracker: A dedicated metrics system to track over-achievements (e.g., closing a $1.5M deal on a $1M target). This will serve as a powerful ROI visualizer for your clients.

Google Calendar Sync: Utilizing the platform's n8n backend to act as a bridge, securely pulling and pushing calendar events and meetings into the app without exposing raw Google API keys on the frontend.

6. The Task Preview Interface
When tapping a task, the modal will display:

Bold Title & Description

Current Progress (0-100% Bar) & Status (To-Do, In Progress, Done)

Date Assigned & Immutable Deadline

Assigned Personnel (Avatars)

File Attachments Grid

In-Task Activity/Chat Feed
